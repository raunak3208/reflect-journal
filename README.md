# 📝 MoodSpace – Personal Journal Web App

MoodSpace is a personal digital journaling web application that helps users record their daily experiences, track moods, and visualize emotional patterns through analytics.  
It is designed to be clean, minimal, and distraction-free — your private space to reflect and grow.

---

## ✨ Features

- 🖊️ **Daily Journal Entries**  
  Write about your day with a clean and simple editor.

- 😊 **Mood Tracking**  
  Add a mood to each entry and reflect on how you felt that day.

- 📊 **Mood Analytics Dashboard**  
  - Average mood score
  - Number of entries
  - Mood trends over time (graph)
  - Entry frequency visualization

- 📁 **Collections**  
  Organize entries into collections like *Daily College*, *Exams*, or custom folders.

- 🔍 **Search & Filters**
  - Search entries
  - Filter by mood
  - Filter by date

- 🔐 **Private & Secure**  
  Your thoughts stay personal and secure.

---

## 🛠️ Tech Stack

- **Frontend:** React / Next.js  
- **Backend:** Node.js  
- **Styling:** CSS / Tailwind (if applicable)  
- **Charts:** Chart-based mood visualization  
- **Package Manager:** npm
